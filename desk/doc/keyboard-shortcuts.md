# Keyboard shortcuts

## Quiz commands

These are the three configured application shortcuts. On macOS, Command is
the primary modifier; elsewhere use Ctrl. Read-only documents cannot be saved
over the original; use **Open editable copy** first.

| Windows/Linux | macOS | Action |
| --- | --- | --- |
| Ctrl-S | Command-S | Save active document |
| Ctrl-Shift-S | Command-Shift-S | Save As |
| Ctrl-O | Command-O | Open document |

Run, rerun, replay and cancellation use their visible buttons; Quiz configures
no shortcuts for them. Escape closes the active dialog or menu. Browser or
operating-system shortcuts may take precedence outside the application.

## Ace source editor

With the editor focused and the **default** keymap selected in Settings:

| Windows/Linux | macOS | Action |
| --- | --- | --- |
| Ctrl-A | Command-A | Select all |
| Ctrl-Z | Command-Z | Undo |
| Ctrl-Shift-Z / Ctrl-Y | Command-Shift-Z / Command-Y | Redo |
| Ctrl-F | Command-F | Find |
| Ctrl-H | Command-Option-F | Replace |
| Ctrl-D | Command-D | Remove line |
| Alt-Up / Alt-Down | Option-Up / Option-Down | Move lines |
| Tab / Shift-Tab | Tab / Shift-Tab | Indent / outdent |
| Ctrl-/ | Command-/ | Toggle comment |
| Ctrl-L | Command-L | Go to line |
| F1 | F1 | Open command palette |

The command palette lists available editor commands and their bindings.
**Settings → Keybindings → Vim** changes editor bindings; the Quiz document
commands above remain application commands. Return to the default keymap if
following an Ace shortcut does not produce the expected action.
